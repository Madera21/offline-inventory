Offline Inventory 1.1.0 updates the original standalone Android app with Expo SDK 58 and the latest inventory workflows.

## Included

- Light and dark themes, expiration alerts, and separate delivery batches.
- Delivery receiving, physical stock counts, packs, favorites, shopping lists, utang and repayments, and daily closing.
- English and Filipino core labels, an in-app How to Use guide, and external backup-file selection.
- Expo SDK 58, React Native 0.88, React 19.3, and matching native dependencies.

## Update the existing app

Download **offline-inventory-1.1.0-2.apk** and install it over the existing Offline Inventory app. **Do not uninstall the old app first.** Android should offer an update. Keep a backup of your inventory before updating.

This release uses the same package (`com.offlineinventory.app`) and signing certificate as the published 1.0.0 APK, with Android version code increased from 1 to 2. The existing database is retained and upgraded through the app's versioned migrations. New stock-batch and store-workflow tables are added while existing products, stock, sales, and photos are preserved.

Expo Go and a development server are not required. Expo Go records live in a separate sandbox; use Backup & Restore to transfer those records to the standalone app.

## Verification

The release includes public APK metadata and SHA256SUMS.txt for integrity checks. Tests and TypeScript pass; APK signature, package, version, and embedded bundle are checked before publication. Physical-device upgrade and smoke testing remain pending.
