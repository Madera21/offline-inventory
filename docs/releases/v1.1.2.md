# Offline Inventory 1.1.2

This update makes it easier to review sales and closing records for a specific day or period.

- Reports includes a calendar for choosing a day, plus Yesterday, Last 30 Days, and custom start/end date ranges.
- Sales totals and best sellers follow the selected period, using the device's local timezone for calendar days.
- Sales Ledger CSV exports can use the selected report period or include all sales. The ledger includes both completed and voided receipts.
- Daily Closing lets you review previous days and their saved cash counts in read-only mode. Choose Today to record current expenses and closing counts.

## Install or update

Download **offline-inventory-1.1.2-4.apk** and open it on your Android phone. Install it over the existing app; do not uninstall first. The package ID and release signing certificate are unchanged, and Android version code increases to 4. Existing inventory, sales, and photos are retained. Keep a separate inventory backup before updating.

If the APK download is incomplete, download **offline-inventory-1.1.2-install.zip**, extract it, and open the APK inside. SHA256SUMS.txt and public APK metadata are included for integrity checks.

This is a standalone app: Expo Go and a development server are not required. No database migration or backup format change is introduced by this update.

## Validation

All 28 Jest suites / 171 tests and TypeScript pass on the release source. The updated report and closing screens were reviewed by the user in Expo Go before release preparation.

The signed APK passed package/version, signature v2/v3, 16 KB alignment, SHA-256, ZIP CRC, ARM native-library, and embedded production-bundle checks. Installing it over 1.1.1 succeeded on the Android emulator; the original installation time and a marker in the app's private files were retained. Standalone startup could not be verified on this x86 emulator: React Native's loader searched the APK's x86_64 library path, while this phone APK contains ARM libraries. Physical-device upgrade and standalone UI checks remain pending.
