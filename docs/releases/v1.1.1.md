# Offline Inventory 1.1.1

This follow-up to 1.1.0 includes the merged inventory usability fixes.

- Stock now shows **remaining / total stocked**, such as 10/10 before a sale and 9/10 afterward.
- Saved products support adding, replacing, removing, and framing their photos from Edit Info.
- How to Use now includes ten interactive lessons with sample controls, guided tasks, and saved progress. Practice does not change your actual inventory or sales.
- Form inputs and checkout stay accessible above the Android keyboard, including modal forms.

## Install or update

Download **offline-inventory-1.1.1-3.apk** and open it on your Android phone. Install it over the existing app; do not uninstall first. The package ID and release signing certificate match 1.0.0 and 1.1.0, and Android version code increases to 3. Existing inventory, sales, and photos are retained. Keep a separate inventory backup before updating.

If your browser's APK download is incomplete or fails verification, download **offline-inventory-1.1.1-install.zip**, extract it, and open the APK inside. SHA256SUMS.txt and public APK metadata are included for integrity checks.

This is a standalone app: Expo Go and a development server are not required. No database migration or backup format change is introduced by this update. Backups report the current app version.

## Validation

All 157 automated tests and TypeScript pass. One UI suite timed out during concurrent native compilation and passed on rerun. The four usability changes were exercised in Expo Go on an Android 16 emulator. The release APK passed package/version, signature v2/v3, 16 KB alignment, ZIP CRC, native-library, and embedded production-bundle checks. Installing the signed APK over 1.1.0 succeeded on the emulator; Android retained the original install time and a marker in the app's private sandbox. Physical-device upgrade testing remains pending; ARM APK runtime checks are limited by the x86 emulator's native-library translation.
